🧊 AeroLauncher

  **AeroLauncher** is a modern, stable Minecraft launcher inspired by the **Frutiger Aero** aesthetic.
  The project combines a glossy, "glass-like" interface with the functionality of Prism Launcher.

  ## ✨ Features
  - **Frutiger Aero Design**: A light-blue color palette, rounded corners, and a glass-effect aesthetic.
  - **Instance Management**: Quickly create, delete, and switch between different game versions.
  - **Auto-Optimization**: Intelligent selection of JVM arguments tailored to your hardware (CPU, GPU, RAM).
  - **Core Support**: Vanilla, Fabric, and Forge.
  - **Flexible Settings**: Full control over RAM allocation, process priority, and network parameters.

  ## 🚀 Quick Start

  ### For Users (EXE)
  Download the file from the **Tags** section and run it.
